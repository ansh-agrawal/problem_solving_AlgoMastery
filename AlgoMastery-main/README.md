# AlgoMastery 🧠💻

![AlgoMastery](https://github.com/sksam284/AlgoMastery/blob/main/images/logo.png?raw=true)

Welcome to **AlgoMastery**, your ultimate playground for mastering **Data Structures and Algorithms (DSA) in Python**! This repository contains **101 curated coding problems** ranging from Easy to Hard, covering **arrays, strings, linked lists, stacks, queues, trees, graphs, dynamic programming, greedy algorithms, binary search, and more**.  

Whether you are preparing for interviews, sharpening your problem-solving skills, or just love algorithmic challenges, this repo has you covered.

---

## 🚀 Features

- **101 Python problems**, divided as:
  - **25 Easy**
  - **50 Medium**
  - **26 Hard**
  - **Well-structured folders**:
    ```
    problems/
        easy/
        medium/
        hard/
    tests/
        easy/
        medium/
        hard/
    ```
- **Stubbed Python solutions** with detailed **docstrings** and **type hints**.
- **Pytest-ready unit tests** for every problem, with **canonical test cases**.
- **Clear problem descriptions** with examples for consistent practice.
- Encourages **hands-on learning**, since solutions are left as TODOs.

## 🎯 Problem Categories

- **Arrays & Two Pointers**: Two Sum, Trapping Rain Water, Merge Intervals, etc.
- **Strings & Sliding Window**: Longest Substring Without Repeating Characters, Group Anagrams, Minimum Window Substring, etc.
- **Linked Lists**: Add Two Numbers, Reverse Linked List, LRU Cache, LFU Cache, etc.
- **Stacks & Queues**: Valid Parentheses, Min Stack, Sliding Window Maximum, etc.
- **Trees & Graphs**: Binary Tree Maximum Path Sum, Number of Islands, Word Ladder, etc.
- **Dynamic Programming**: House Robber, Coin Change, Longest Increasing Subsequence, Edit Distance, etc.
- **Greedy Algorithms**: Jump Game, Candy, Best Time to Buy and Sell Stock II, etc.
- **Binary Search**: Search in Rotated Sorted Array, Median of Two Sorted Arrays, Koko Eating Bananas, etc.
- **Bit Manipulation / Subsets**: Subsets, Pow(x, n), etc.

## ⚡ How to Use

1. Clone the repo:
```bash
git clone https://github.com/sksam284/AlgoMastery.git
cd AlgoMastery
```

2. Install pytest (if not installed):
```bash
pip install pytest
```

3. Run all tests:
```bash
pytest tests/
```

4. Pick any problem in `problems/` and implement your solution. Run the corresponding test to check correctness.
